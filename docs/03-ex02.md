# Модуль 03, ex02: Current

> Третье упражнение: вкладка **Currently** становится понятной «с одного взгляда». Сабж просит показать место, температуру, описание, иконку и ветер так, чтобы пользователь всё понял **не дольше чем за три секунды**. Данные те же, что и в модуле 02; меняется **порядок, размер и оформление**. Новые темы: **визуальная иерархия**, **иконки погоды по коду WMO**, **`is_day`: солнце или луна**, **композиция карточки**, **адаптивность без overflow**.

> **Честная пометка о проверке.** Код написан **без запуска** (Flutter SDK в среде подготовки нет). Синтаксис проверен парсером; `flutter analyze`, `flutter test` и вид на устройстве не проверялись. Правило «три секунды» **тестом не проверить**: тест лишь доказывает, что всё на экране без прокрутки и иерархия размеров соблюдена. Остальное смотрите глазами (раздел 6).

## 1. Задача и с чего начать

### 1.1 Условия сабжа

- **Папка сдачи:** `mobileModule03`; **файлы:** `advanced_weather_app`.
- **Требования ex02, вкладка Currently:**
  - **местоположение**: город, регион, страна;
  - **температура**;
  - **описание погоды**;
  - **иконка** погоды;
  - **скорость ветра**;
  - всё это **понятно за 3 секунды**.

### 1.2 Проблема

В модуле 02 вкладка показывала все данные, но «ровным слоем»: текст одного размера, описание не отличается от ветра, иконки нет. Чтобы найти температуру, надо **читать**. Задача этого упражнения превратить чтение в **сканирование глазами**.

### 1.3 Требования

**Функциональные:** на экране сразу видны шесть вещей: город, регион и страна, иконка, температура, описание, ветер.

**Нефункциональные:**

- **Иерархия:** самое важное самое крупное: температура и иконка; потом город; потом описание; ветер мельче всего.
- **Читаемость** на фоне-картинке (контраст не ниже 4,5:1).
- **Адаптивность:** без overflow на узком экране (320 px), в ландшафте, при крупном системном шрифте.
- **Иконка не обманывает:** ночью не светит солнце.

### 1.4 Что не входит в задачу (non-goals)

- Давление, влажность, «ощущается как», УФ-индекс: сабж их не просит.
- Анимированные иконки (дождь, который идёт).
- Единицы измерения: переключатель °C/°F.
- Свои картинки-иконки погоды: нам хватает встроенных.

### 1.5 Критерии успеха

- [ ] Все шесть элементов видны сразу, **без прокрутки** на телефоне.
- [ ] Температура самая крупная надпись на экране.
- [ ] Иконка соответствует погоде (дождь: капля, снег: снежинка, ясно: солнце...).
- [ ] Ночью при ясном небе луна, а не солнце.
- [ ] В ландшафте и при крупном шрифте нет жёлто-чёрных полос overflow.
- [ ] Незнакомый человек за 3 секунды отвечает: «где, сколько градусов, что за погода, дует ли ветер».

### 1.6 Первый шаг (spike)

**Проверка «трёх секунд» на старом экране.** Покажите вкладку модуля 02 знакомому на 3 секунды, уберите и задайте четыре вопроса: «Где? Сколько градусов? Что за погода? Дует ли?». Запишите, на чём споткнулся. Обычно это температура (потеряна среди строк одинакового размера) и «что за погода» (надо читать слова). Это ваш «базовый уровень»: после доработки замерьте так же.

## 2. Теория

### 2.1 Словарик (простыми словами)

| Слово | Что это |
|---|---|
| **Визуальная иерархия** | Порядок важности, который виден без чтения: самое важное крупнее, ярче, выше. |
| **Масштаб шрифтов** | Набор готовых размеров текста в теме (`TextTheme`): `displayLarge`, `headlineSmall`, `titleLarge`, `titleMedium`... |
| **`displayLarge`** | Самый крупный стиль текста в теме (57 пикселей по умолчанию). Для «героя» экрана. |
| **Код погоды WMO** | Число от 0 до 99, которым метеорологи шифруют погоду: 0 ясно, 61 дождь... Open-Meteo отдаёт его в `weather_code`. |
| **`switch`-выражение** | Короткая запись «по значению выбери результат»: `switch (code) { 0 => ..., 3 => ..., _ => ... }`. |
| **`_` в `switch`** | «Всё остальное». Ловит значения, которых нет в списке выше. |
| **`IconData` и `Icon`** | `IconData` это «номер значка» в шрифте иконок; `Icon` рисует его заданного размера и цвета. |
| **Шрифт иконок Material Icons** | Файл, зашитый во Flutter: значки лежат в нём как символы. Картинок и пакетов не нужно. |
| **`is_day`** | Поле Open-Meteo: 1 если в этом месте сейчас день, 0 если ночь. |
| **`Center`** | Виджет, ставящий ребёнка по центру. |
| **`SingleChildScrollView`** | Делает содержимое прокручиваемым, если оно не помещается. |
| **`Column(mainAxisSize: min)`** | Колонка, занимающая **ровно** высоту содержимого (а не всё доступное место). |
| **`ConstrainedBox(maxWidth)`** | Ограничитель: «не шире N пикселей». |
| **`Flexible`** | Внутри `Row`/`Column` разрешает ребёнку сжаться, если места мало (текст переносится). |
| **Overflow** | «Не влезло»: Flutter рисует жёлто-чёрные полосы на краю виджета, который больше места. |
| **Текстовый масштаб (`textScale`)** | Системная настройка «размер шрифта». Увеличивает **весь** текст, поэтому раскладка должна выдерживать ×1,5 и ×2. |
| **Допустимая цель контраста для иконок** | Для значков и крупной графики WCAG требует 3:1 (мягче, чем 4,5:1 для текста). |

### 2.2 Правило трёх секунд: как читают экран

Взгляд на экран идёт **по размеру, потом по яркости, потом сверху вниз**. Из этого строим порядок:

| Порядок | Что | Чем выделено |
|---|---|---|
| 1 | иконка и температура | крупнейшие: иконка 96 px, температура `displayLarge` (57 px, лёгкий вес 300) |
| 2 | город, регион, страна | жирный `headlineSmall` (24 px) сверху |
| 3 | описание | `titleLarge` (22 px) прямо под температурой |
| 4 | ветер | `titleMedium` (16 px) + иконка-подсказка, внизу |

Сабж не случайно называет «понятно за 3 секунды»: для главного вопроса «брать ли куртку» достаточно температуры и иконки, и они занимают **центр** экрана.

### 2.3 Иконка по коду WMO

Open-Meteo даёт погоду числом (раздел [02-ex02, 2.2](02-ex02.md#22-коды-погоды-wmo)); текст мы расшифровывали в `describeWeatherCode`. Теперь то же число превращаем в **значок**: `switch` по семействам кодов:

| Коды WMO | Значит | Иконка (Material) |
|---|---|---|
| 0, 1 | ясно, в основном ясно | `wb_sunny` (день) / `nights_stay` (ночь) |
| 2 | переменная облачность | `wb_cloudy` |
| 3 | пасмурно | `cloud` |
| 45, 48 | туман | `foggy` |
| 51-57 | морось | `grain` |
| 61-67, 80-82 | дождь, ливни | `water_drop` |
| 71-77, 85-86 | снег | `ac_unit` |
| 95-99 | гроза | `thunderstorm` |
| всё остальное | неизвестно | `help_outline` («?») |

Почему «`_` → вопрос», а не ошибка: список кодов WMO могут расширить, а экран погоды не должен падать из-за нового числа.

Почему встроенные иконки, а не картинки: ни ассетов, ни лицензий, ни разрешений; масштабируются как текст (чёткие в любом размере); цвет задаётся кодом. Минус: стиль «простой». Для красоты можно взять пакет иконок погоды (раздел 5).

### 2.4 День и ночь: `is_day`

Солнце ночью выглядит как баг. Open-Meteo умеет сообщить, день сейчас в **этом месте** или ночь: поле `is_day` (1 или 0). Мы просим его в `current` и в `hourly`:

```text
current=temperature_2m,weather_code,wind_speed_10m,is_day
hourly=temperature_2m,weather_code,wind_speed_10m,is_day
```

В коде это превращается в `bool isDay`. Важные решения:

- **По умолчанию «день»**: если поля нет (API изменился), считаем днём и не падаем: это украшение, а не данные (`bool _isDay(Object? v) => v is num ? v != 0 : true;`).
- **Различаем только ясное небо** (коды 0, 1): облако и дождь выглядят одинаково днём и ночью.
- `is_day` приходит **для места**, а не для телефона: в Сиднее ночь, когда в Барселоне день.

> Для вкладки Weekly (`DailyWeather`) `isDay` нет: «день недели» это сутки целиком, и там ясное небо всегда рисуется солнцем.

### 2.5 Цвет иконки и контраст

Иконка это графика, а не текст: WCAG требует для неё **3:1**. Расчёт на самой светлой точке «стекла» (то есть на худшем месте картинки):

| Иконка | Цвет | Контраст, худшая точка | Медиана |
|---|---|---|---|
| солнце | `#FFC857` (янтарь) | **4,64:1** | 8,2:1 |
| луна | `#CFD8FF` (бледно-голубой) | **5,07:1** | 9,0:1 |
| остальные | `#E8F1FF` (почти белый) | **6,27:1** | 11,1:1 |
| белый текст | `#FFFFFF` | **7,14:1** | 12,6:1 |

Все выше нормы 3:1 для графики и 4,5:1 для текста. Цвет солнца жёлтый **не из реализма**, а чтобы оно сразу отличалось от облаков.

### 2.6 Композиция: `Center` + прокрутка + `Column(min)`

Задача: карточка должна быть **по центру**, когда места много, и **прокручиваться**, когда мало (ландшафт, крупный шрифт). Решение:

```dart
Center(                                    // 1. центр
  child: SingleChildScrollView(            // 2. прокрутка, если не влезает
    padding: EdgeInsets.all(16),
    child: ConstrainedBox(                 // 3. не шире 480
      constraints: BoxConstraints(maxWidth: 480),
      child: GlassCard(
        child: Column(
          mainAxisSize: MainAxisSize.min,  // 4. высота ровно по содержимому
          children: [...],
        ),
      ),
    ),
  ),
)
```

Почему именно так: `SingleChildScrollView` даёт ребёнку **бесконечную** высоту. Если бы вместо `mainAxisSize.min` стоял `max` (значение по умолчанию), колонка попыталась бы занять бесконечность и Flutter бросил бы ошибку. `Center` по центру кладёт то, что **меньше** окна; то, что больше, прокручивается.

### 2.7 Крупный шрифт и узкий экран

Пользователь с плохим зрением ставит системный шрифт ×1,5-2. Текст растёт, а карточка нет, поэтому:

- описание и ветер должны **переноситься**, а не вылезать (`Flexible` вокруг текста в `Row`; `Text` по умолчанию переносится сам, но в `Row` без `Flexible` он считается бесконечной ширины);
- название города ограничено `maxLines: 2` и `ellipsis`: «Llanfairpwllgwyngyll...» не съест экран;
- всё лежит в прокрутке: что не влезло, можно досмотреть.

## 3. Декомпозиция и решения

Части: **(а)** `weatherIcon` / `weatherIconColor`; **(б)** `is_day` через слой данных; **(в)** `LocationHeader`; **(г)** `CurrentView`; **(д)** `MessageView` (ошибки в том же стиле); **(е)** тесты.

### Решение 1: одна карточка по центру, а не «растянуть на экран»

- **Варианты:** (а) центральная «стеклянная» карточка; (б) данные прямо на фоне без плашки; (в) на всю ширину и высоту; (г) hero-блок + нижняя таблица подробностей.
- **Выбрано:** (а).
- **Почему:** всё внимание на небольшом блоке, фон остаётся виден вокруг (красота), «стекло» гарантирует читаемость. (б) нарушает читаемость (ex01, раздел 2.5). (в) на планшете растянет цифры на пол-экрана. (г) для четырёх значений избыточно.
- **Что теряем / риски:** на очень широком экране карточка 480 px выглядит «одиноко»; это приемлемо.

### Решение 2: иерархия размеров (иконка 96, температура 57, город 24, описание 22, ветер 16)

Числа это размеры стилей темы (`displayLarge`, `headlineSmall`, `titleLarge`, `titleMedium`), а не выдуманные: так текст масштабируется вместе с настройками и согласуется с остальным приложением. Вес температуры `w300` (лёгкий): очень крупные цифры тонкого начертания выглядят изящнее и «дороже», жирные были бы тяжёлыми.

### Решение 3: иконки из Material Icons, а не пакет и не картинки

- **Варианты:** (а) встроенный шрифт Material Icons; (б) пакет иконок погоды (например, `weather_icons`); (в) свои PNG/SVG; (г) эмодзи.
- **Выбрано:** (а).
- **Почему:** ноль зависимостей и лицензий, цвет из кода, масштабирование без потери чёткости. (г) эмодзи выглядят по-разному на каждой платформе и плохо управляются цветом. (б) красивее, но внешняя зависимость.
- **Что теряем / риски:** набор иконок небогат (нет отдельных «лёгкий дождь» и «сильный»). Различие по тексту-описанию рядом.

### Решение 4: `switch` по семействам кодов, а не по каждому коду

29 кодов WMO сводятся к 8 понятным картинкам: человеку важно «дождь», а не «слабый ливень или умеренный». Точность даёт текст рядом.

### Решение 5: `is_day` как необязательное поле

Если API перестанет его отдавать, приложение не сломается, а лишь станет рисовать солнце ночью. Это поведение «деградирует мягко» (graceful degradation).

### Решение 6: цвет иконки: жёлтое солнце, светлая луна, остальное светлое

Мы не раскрашиваем всё в «реалистичные» цвета (серое облако, синяя капля): они хуже читаются на тёмном стекле. Единственное цветовое пятно жёлтое солнце: оно сразу кричит «ясно».

### Решение 7: `Row` для ветра с `Flexible`

Иконка `air` + текст «Wind: 10.5 km/h». `Flexible` не даёт тексту вылезти при крупном шрифте.

### Решение 8: `MessageView` на том же «стекле»

Ошибка («город не найден», «нет сети») показывается в такой же карточке по центру: единый стиль, читаема на фоне. Иконка по типу ошибки (`switch` по sealed-классу `WeatherFailure`: компилятор не даст забыть новый вид ошибки).

### Решение 9: `maxLines: 2` у названия города

Редкий, но реальный случай: длинное название (например, валлийская деревня) или составное. Два строки максимум, дальше многоточие.

## 4. Разбор кода

### 4.1 Слои по порядку

#### Слой 1: spike

Проверка трёх секунд на старом экране (раздел 1.6): записали «боли».

#### Слой 2: `is_day` в данных

В `WeatherService` (`lib/services/weather_service.dart`) изменились три места:

```dart
'current': 'temperature_2m,weather_code,wind_speed_10m,is_day',     // просим поле
'hourly':  'temperature_2m,weather_code,wind_speed_10m,is_day',
...
final List<Object?>? hourDay = hourly['is_day'] as List<Object?>?;  // может отсутствовать
...
isDay: _isDay(hourDay?[i]),                                         // час
isDay: _isDay(current['is_day']),                                   // «сейчас»
...
bool _isDay(Object? value) => value is num ? value != 0 : true;     // нет поля: день
```

Разбор:

- `as List<Object?>?`: приведение к списку **или null** (знак `?` после типа значит «может быть null»). Если ключа `is_day` нет, `hourly['is_day']` даёт `null`, приведение проходит, а `hourDay?[i]` безопасно даёт `null`.
- `value is num ? value != 0 : true`: «если пришло число, то `1` значит день; если не число или нет, то день».
- В моделях: `this.isDay = true`: значение по умолчанию у именованного параметра; старый код, не знающий про `isDay`, продолжает работать.

#### Слой 3: иконка по коду

**`lib/ui/weather_icon.dart`**:

```dart
import 'package:material_ui/material_ui.dart';

// Иконка по коду погоды WMO (тот же код, что превращается в текст в
// describeWeatherCode). Иконки берём из встроенного шрифта Material Icons:
// ни картинок, ни пакетов, ни лицензий, и они масштабируются как текст.
//
// [isDay] нужен только ясному небу: днём солнце, ночью луна.
IconData weatherIcon(int code, {bool isDay = true}) => switch (code) {
  0 || 1 => isDay ? Icons.wb_sunny : Icons.nights_stay,
  2 => Icons.wb_cloudy,
  3 => Icons.cloud,
  45 || 48 => Icons.foggy,
  51 || 53 || 55 || 56 || 57 => Icons.grain, // морось
  61 || 63 || 65 || 66 || 67 || 80 || 81 || 82 => Icons.water_drop, // дождь
  71 || 73 || 75 || 77 || 85 || 86 => Icons.ac_unit, // снег
  95 || 96 || 97 || 99 => Icons.thunderstorm,
  _ => Icons.help_outline, // незнакомый код: не падаем, а показываем «?»
};

// Цвет иконки: солнце жёлтое, луна бледная, остальное светлое.
// Цвета подобраны под тёмный фон (контраст важнее «реализма»).
Color weatherIconColor(int code, {bool isDay = true}) => switch (code) {
  0 || 1 => isDay ? const Color(0xFFFFC857) : const Color(0xFFCFD8FF),
  _ => const Color(0xFFE8F1FF),
};
```

Разбор:

- `IconData weatherIcon(int code, {bool isDay = true}) => switch (code) {...};`: функция в одну строку-выражение. `{bool isDay = true}` это **именованный** необязательный параметр: вызывают `weatherIcon(0, isDay: false)`.
- `0 || 1 => isDay ? Icons.wb_sunny : Icons.nights_stay`: **«или»-шаблон**: ветка срабатывает при `0` **или** `1`. Внутри обычный тернарный оператор `условие ? а : б`.
- `51 || 53 || 55 || 56 || 57`: пять кодов в одной ветке.
- `_ => Icons.help_outline`: всё остальное.
- `weatherIconColor` по той же схеме выбирает цвет: солнце, луна или «светлый».

> **Риск «непроверенных имён иконок»**: названия (`foggy`, `nights_stay`, `thunderstorm`, `water_drop`) сверены только со списком иконок Flutter 3.35. Если `flutter analyze` скажет `undefined_identifier` у какой-то иконки в Flutter 3.50 (иконку переименовали), замените на близкую из [каталога иконок](https://fonts.google.com/icons) и поправьте `test/weather_icon_test.dart`.

#### Слой 5: вкладка Currently

**`lib/ui/current_view.dart`**:

```dart
import 'package:material_ui/material_ui.dart';

import '../models/weather_report.dart';
import 'formatters.dart';
import 'glass_card.dart';
import 'location_header.dart';
import 'weather_icon.dart';

// Вкладка Currently. Читается за три секунды, потому что порядок сверху вниз
// это порядок важности, а размер шрифта показывает, что главное:
//   1. где (город, регион, страна);
//   2. какая погода (крупная иконка и очень крупная температура);
//   3. словами (описание);
//   4. ветер (мельче всего).
class CurrentView extends StatelessWidget {
  const CurrentView({super.key, required this.report});

  final WeatherReport report;

  @override
  Widget build(BuildContext context) {
    final TextTheme textTheme = Theme.of(context).textTheme;
    final CurrentWeather current = report.current;

    // Center + SingleChildScrollView + Column(min): по центру, пока места хватает;
    // в ландшафте, с клавиатурой и при крупном шрифте прокручивается без overflow.
    return Center(
      child: SingleChildScrollView(
        padding: const EdgeInsets.all(16),
        child: ConstrainedBox(
          constraints: const BoxConstraints(maxWidth: 480),
          child: GlassCard(
            padding: const EdgeInsets.symmetric(horizontal: 24, vertical: 28),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                LocationHeader(place: report.place),
                const SizedBox(height: 24),
                Icon(
                  weatherIcon(current.weatherCode, isDay: current.isDay),
                  size: 96,
                  color: weatherIconColor(current.weatherCode, isDay: current.isDay),
                ),
                const SizedBox(height: 8),
                Text(
                  formatTemperature(current.temperature),
                  style: textTheme.displayLarge?.copyWith(fontWeight: FontWeight.w300),
                  textAlign: TextAlign.center,
                ),
                const SizedBox(height: 8),
                Text(
                  current.description,
                  style: textTheme.titleLarge,
                  textAlign: TextAlign.center,
                ),
                const SizedBox(height: 16),
                Row(
                  mainAxisSize: MainAxisSize.min,
                  children: [
                    const Icon(Icons.air, size: 22),
                    const SizedBox(width: 8),
                    // Flexible: при крупном шрифте на узком экране текст переносится,
                    // а не вылезает за край (иначе overflow в Row).
                    Flexible(
                      child: Text(
                        'Wind: ${formatWind(current.windSpeed)}',
                        style: textTheme.titleMedium,
                      ),
                    ),
                  ],
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }

```

Разбор:

- Каркас `Center` → `SingleChildScrollView` → `ConstrainedBox` → `GlassCard` → `Column(min)`: раздел 2.6.
- Порядок детей и промежутки: заголовок, 24, иконка 96, 8, температура, 8, описание, 16, ветер: промежутки **группируют**: иконка и температура рядом (одна группа), ветер отделён.
- `Icon(weatherIcon(current.weatherCode, isDay: current.isDay), size: 96, color: weatherIconColor(...))`: размер 96 и цвет по коду.
- `formatTemperature(current.temperature)`: «12.3°C» (форматтер из модуля 02, один знак после запятой).
- `textTheme.displayLarge?.copyWith(fontWeight: FontWeight.w300)`: берём стиль темы и **меняем только вес**; `?.` на случай `null`.
- `Row(mainAxisSize: min, children: [Icon(Icons.air), SizedBox(width: 8), Flexible(Text(...))])`: ветер.

#### Слой 6: ошибки в том же стиле

**`lib/ui/message_view.dart`**:

```dart
import 'package:material_ui/material_ui.dart';

import '../failures.dart';
import 'glass_card.dart';

// Сообщение об ошибке посреди вкладки. Висит, пока его не заменят данные.
class MessageView extends StatelessWidget {
  const MessageView({super.key, required this.failure});

  final WeatherFailure failure;

  // switch по sealed-классу: компилятор следит, что иконка есть для каждой ошибки.
  IconData get _icon => switch (failure) {
    LocationDeniedFailure() ||
    LocationDeniedForeverFailure() ||
    LocationServiceDisabledFailure() ||
    LocationUnavailableFailure() => Icons.location_off,
    CityNotFoundFailure() => Icons.search_off,
    ConnectionFailure() => Icons.cloud_off,
    ServerFailure() => Icons.error_outline,
  };

  @override
  Widget build(BuildContext context) {
    final ThemeData theme = Theme.of(context);

    // Сообщение лежит на «стекле»: читается на любом фоне. Иконка цвета ошибки
    // (в тёмной теме он светло-розовый, контрастный), текст обычным светлым.
    return Center(
      child: SingleChildScrollView(
        padding: const EdgeInsets.all(24),
        child: ConstrainedBox(
          constraints: const BoxConstraints(maxWidth: 480),
          child: GlassCard(
            padding: const EdgeInsets.all(24),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                Icon(_icon, size: 48, color: theme.colorScheme.error),
                const SizedBox(height: 16),
                Text(
                  failure.message,
                  style: theme.textTheme.bodyLarge,
                  textAlign: TextAlign.center,
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}
```

- `IconData get _icon => switch (failure) {...}`: **геттер** (вычисляемое свойство) с `switch` по sealed-классу. Образец `LocationDeniedFailure() || ...` распознаёт объект **по типу**. Если добавить новый вид ошибки и забыть тут ветку, компилятор скажет «switch не исчерпывающий».
- Иконка цвета `colorScheme.error` (в тёмной теме светло-розовый), текст обычный.

#### Слой 7: тесты

Группа «ex02» в `test/design_test.dart`, плюс `test/weather_icon_test.dart`. Главная проверка «три секунды»:

```dart
setScreen(tester, const Size(390, 844));
await pumpApp(tester);

final Rect screen = const Offset(0, 0) & const Size(390, 844);
for (final Finder finder in [
  onPage(find.text('Barcelona')),            // город

```

`Offset(0, 0) & Size(390, 844)`: оператор `&` создаёт `Rect` из точки и размера. `getCenter` даёт центр виджета; если он внутри экрана, виджет видно без прокрутки.

Иерархия: `size('12.3°C') > size('Partly cloudy') > size('Wind: ...')`. Ночь: `rig.weather.reportBuilder` подставляет отчёт с `isDay: false` и код 0, а тест ожидает `Icons.nights_stay` и не ожидает `Icons.wb_sunny`. В `weather_icon_test.dart`: у каждого из 29 известных кодов есть иконка (не «?»), у неизвестного «?», день и ночь различаются только у ясного неба.

### 4.2 Симуляция: «Barcelona, 12.3°C, переменная облачность, ночь»

| № | Что | Результат |
|---|---|---|
| 1 | API: `current = {temperature_2m: 12.3, weather_code: 2, wind_speed_10m: 10.5, is_day: 0}` | `CurrentWeather(12.3, 2, 10.5, isDay: false)` |
| 2 | `weatherIcon(2, isDay: false)` | ветка `2 => Icons.wb_cloudy` (день/ночь не влияет) |
| 3 | `weatherIconColor(2)` | `_ => 0xFFE8F1FF` |
| 4 | `describeWeatherCode(2)` | «Partly cloudy» |
| 5 | экран сверху вниз | «Barcelona» (жирный), «Catalonia, Spain», облако 96 px, «12.3°C», «Partly cloudy», ветер «Wind: 10.5 km/h» |

А при коде 0 и `is_day: 0` на шаге 2 получилась бы луна `nights_stay` бледно-голубого цвета.

### 4.3 Симуляция: крупный шрифт ×2 на узком экране

Экран 320 px шириной, системный шрифт ×2. Карточка получает ширину `320 − 2×16 (отступ прокрутки) = 288`, а на текст остаётся `288 − 2×24 (внутренний отступ) = 240` px. Температура вырастает до 114 px, описание до 44, ветер до 32, город до 48 в две строки. «Wind: 10.5 km/h» при 32 px уже не помещается в 240 − 22×2 (иконка) − 8 и **переносится на вторую строку** благодаря `Flexible`. Высота карточки теперь больше окна, поэтому `SingleChildScrollView` даёт её **докрутить**, а overflow-полос нет. Именно это проверяет тест «все вкладки при разных размерах и крупном шрифте».

### 4.4 Симуляция: нет региона и страны

Обратный геокодер не ответил, место `Nowhere` без региона и страны (`subtitle` пустой). `LocationHeader` рисует только название. Без `if (place.subtitle.isNotEmpty)` была бы пустая строка и «дыра» между названием и иконкой.

## 5. Альтернативы

| Подход | Суть | Плюсы | Минусы | Когда подойдёт |
|---|---|---|---|---|
| **Material Icons + `switch` по коду** (выбрано) | значки из встроенного шрифта | без зависимостей и лицензий, цвет из кода | скромный набор | наш случай |
| Пакет иконок погоды | готовые «солнце, облако, дождь» | красивее, больше вариантов | зависимость, лицензия, обновления | дизайн важнее |
| Свои SVG (`flutter_svg`) | вектор, любой стиль | полный контроль | пакет, ассеты, работа дизайнера | брендированное приложение |
| Анимации (Lottie, Rive) | двигающиеся иконки | очень эффектно | вес, зависимость, батарея | витрина |
| Эмодзи (☀️🌧) | текст | ноль кода | разные на платформах, не красятся | прототип |
| Иконка по `is_day` только в ясную погоду (выбрано) | луна вместо солнца | достаточно для понятности | облако ночью то же | наш случай |
| Иконка день/ночь для каждого кода | свой набор ночных иконок | точнее | вдвое больше иконок | если хватает ресурсов |
| Рассчитывать день/ночь самим (восход/закат) | без `is_day` | независимость от API | нужны координаты, формула, часовой пояс | оффлайн |
| Hero-блок + таблица подробностей | карточка + «ощущается», влажность | информативнее | сабж не просит | расширение |
| Без «стекла», данные прямо на фоне | чище | уязвимо для читаемости (ex01, 2.5) | нужна однородная картинка | фон без светлых пятен |

## 7. Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| Везде иконка «?» | Код погоды не распознан (в `switch` его нет) | Добавить код в `weatherIcon`; проверить, что `weather_code` парсится как `int` |
| Ночью светит солнце | `is_day` не запрошен или не разобран | Проверить параметры `current`/`hourly` и `_isDay` |
| `The getter 'foggy' isn't defined for the type 'Icons'` | Иконку переименовали в новой версии Flutter | Заменить на аналог из каталога иконок, обновить тест |
| `RenderFlex overflowed by N pixels` в `Row` | Текст без `Flexible` при крупном шрифте | Обернуть текст в `Flexible` |
| `Vertical viewport was given unbounded height` | Колонка с `mainAxisSize.max` внутри прокрутки | `mainAxisSize: MainAxisSize.min` |
| Карточка прижата к верху, а не по центру | Нет `Center` или `SingleChildScrollView` занял всю высоту | `Center` снаружи, `Column(min)` внутри |
| Температура «12.299999999» | Не форматируется | `formatTemperature` (`toStringAsFixed(1)`) |
| Два знака `°` | В форматтере и в тексте | Оставить в одном месте |
| Тест «всё на экране» падает на маленьком окне | Окно 390×844 в тесте, а в тесте другой размер | Использовать `setScreen` перед `pumpApp` |
| Тест иконок падает для кода, который «есть» | Разные списки: в `describeWeatherCode` и `weatherIcon` | Синхронизировать списки кодов |

## 8. Безопасность и риски

- **Иконка не заменяет текст.** Она подсказывает; точное состояние даёт описание рядом. Не полагайтесь только на иконку: слепой пользователь её не увидит (поэтому текст остаётся, а `Icon` для скринридера можно подписать `semanticLabel`).
- **Данные могут устареть.** «Сейчас» это момент запроса, а не момент просмотра: после долгого простоя нужен повторный запрос (вне темы).
- **Неверный `is_day`.** Мы верим API. На полюсах в полярную ночь или день он честно держится в одном значении: это не баг.
- **Непроверенные имена иконок** (раздел 4.1, слой 3).
- **Субъективность «трёх секунд».** Тест её не измеряет. Проверка на живых людях это единственная настоящая проверка.

## 10. Что запомнить

**Dart:**

- `switch`-выражение: `switch (x) { 0 || 1 => a, 2 => b, _ => c }`; `||` внутри ветки это «или»-шаблон, `_` «всё остальное».
- Именованный параметр с значением по умолчанию: `{bool isDay = true}`.
- `as List<Object?>?` приводит к «списку или null»; `?[i]` безопасно берёт элемент у возможного `null`.
- `if` внутри списка виджетов: `if (условие) Text(...)`.
- `Offset & Size` даёт `Rect`.

**Flutter:**

- `Center` + `SingleChildScrollView` + `Column(mainAxisSize: min)`: по центру, пока влезает, и прокрутка, когда нет.
- В прокручиваемом месте колонка без `mainAxisSize.min` ломается («unbounded height»).
- Текст в `Row` оборачивайте в `Flexible`, иначе при крупном шрифте будет overflow.
- Стили текста берите из `Theme.of(context).textTheme` и меняйте через `copyWith`.
- `sealed`-класс и `switch`: компилятор проверяет, что учтены все виды ошибок.

**Дизайн:**

- Иерархия это размер, вес и положение: самое важное крупнее и выше.
- Иконки и графика нужны с контрастом не ниже 3:1, текст не ниже 4,5:1.
- Украшения (иконка дня/ночи) должны «деградировать мягко»: нет данных, значит безопасное значение по умолчанию.
- «Три секунды» проверяют на людях, а не тестами.
