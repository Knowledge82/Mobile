## 1. Задача и с чего начать

### 1.1 Условия сабжа

- **Папка сдачи:** `mobileModule00`

- **Запрещённые функции:** нет

### 1.2 Проблема

Собрать интерфейс калькулятора: заголовок, поле выражения, поле результата и кнопки. На этом этапе нужен только **внешний вид и отладочный вывод**.

### 1.3 Требования

**Функциональные:**

1. **AppBar** сверху с заголовком **«Calculator»**.
2. **Два `TextField`**: один для выражения, один для результата. Пока в обоих отображается **«0»**.
3. Кнопки:
   - цифры от 0 до 9;
   - `.` для десятичных чисел;
   - `AC`: сброс выражения и результата;
   - `C`: удаление последнего символа выражения;
   - `=`: вывод результата выражения;
   - операторы `+`, `-`, `*`, `/`.
4. **Отладка:** для каждой нажатой кнопки выводить её текст в debug-консоль (в картинке сабжа вид строки: `button pressed :AC`).
5. Дисплей должен быть **адаптивным** для всех устройств (телефон, планшет и т. д.).

**Нефункциональные:**

1. `flutter analyze` без замечаний, `flutter test` зелёный.
2. Нет overflow ни в портрете, ни в ландшафте.

### 1.4 Что не входит в задачу (non-goals)

- Реальные вычисления и обработка `=`, `C`, `AC` (это ex03). Здесь кнопки только печатают свой текст.
- Цвета и оформление как на картинке сабжа.
- Кнопка `00` с картинки: в списке сабжа её нет, а сабж предупреждает, что демо может содержать необязательные дополнения.

### 1.5 Критерии успеха

- [ ] Проект называется `ex02`.
- [ ] AppBar с текстом «Calculator».
- [ ] Два поля с «0».
- [ ] Все кнопки из списка присутствуют.
- [ ] Каждое нажатие печатает текст кнопки в консоль.
- [ ] Нормальный вид на телефоне (портрет и ландшафт) и на широком экране (планшет).
- [ ] `flutter analyze` и `flutter test` чистые.
